# FILOSOFÍA OPERATIVA

- intuitivo,
- robusto,
- visualmente limpio,
- difícil de romper por error humano.

---

# PRINCIPIOS OBLIGATORIOS

## 1. CLARIDAD VISUAL

Priorizar:
- estructura limpia,
- jerarquía clara,
- espacios visuales,
- agrupaciones lógicas,
- colores moderados y funcionales,
- legibilidad inmediata.

Evitar:
- saturación visual,
- exceso de colores,
- tablas caóticas,
- diseños recargados,
- exceso de información simultánea.

---

## 2. REDUCCIÓN DE ERRORES HUMANOS

Siempre implementar cuando tenga sentido:
- validación de datos,
- listas desplegables,
- formatos protegidos,
- detección de duplicados,
- alertas visuales,
- restricciones de edición,
- formatos automáticos,
- comprobaciones de integridad.

---

## 3. EFICIENCIA OPERATIVA

Cada documento debe minimizar:
- clicks,
- escritura manual,
- duplicación de datos,
- pasos repetitivos,
- búsquedas innecesarias.

Buscar:
- automatización,
- autocompletado,
- referencias automáticas,
- generación dinámica de datos,
- reutilización inteligente.

---

## 4. FEEDBACK INSTANTÁNEO

El usuario debe entender inmediatamente:
- qué campos faltan,
- qué datos son incorrectos,
- qué documentos están pendientes,
- qué registros tienen errores,
- qué acciones deben realizarse.

Usar:
- formato condicional,
- estados visuales,
- indicadores claros,
- avisos simples,
- mensajes entendibles.

---

# ESTÁNDARES DE EXCEL

## SIEMPRE

Usar:
- tablas estructuradas,
- nombres claros,
- columnas coherentes,
- formatos homogéneos,
- filtros,
- segmentaciones cuando aporten valor,
- fórmulas robustas,
- referencias limpias,
- estructura escalable.

---

## EVITAR

- fórmulas extremadamente complejas innecesarias,
- hojas desordenadas,
- columnas sin nombre claro,
- macros peligrosas,
- dependencias frágiles,
- exceso de hojas innecesarias,
- celdas fusionadas abusivas.
